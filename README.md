## Menjalankan
Buka terminal di folder ini, lalu jalankan contoh:
```bash
python bab01_pengenalan.py
python bab02_variabel_tipe_data.py
```
Bab 03 dan Bab 09 meminta input dari pengguna. Bab 11 membaca/menyiapkan `nilai.csv`.

Untuk bagian pandas pada Bab 11:
```bash
python -m pip install pandas
```

## Catatan penting
- Paket ini merupakan draf kerja berdasarkan contoh kode dalam PDF. Pelajari dan tulis ulang sendiri sesuai instruksi dosen, lalu uji setiap file.
- Jangan mengganti folder `python_dasar` lama yang sudah Anda miliki. Salin file yang diperlukan ke folder lama agar pekerjaan sebelumnya tetap ada.
- Beberapa contoh error pada slide (misalnya assignment ke tuple) disimpan sebagai komentar agar satu file dapat dijalankan dari awal sampai akhir.
- Hasil `randint()` pada Bab 10 berubah-ubah setiap kali dijalankan.
